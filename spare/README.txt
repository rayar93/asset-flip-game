Assets kept for items still open in sprints.txt (boss roar, enemy/boss death, double jump,
enemy movement and idle, door sounds, menu sounds, boss intro music, pumpkin decorations,
lava/torch/mushroom lights, landing dust and death particles, spare enemy and player frames).

The .gdignore file here tells Godot to skip this folder entirely: nothing in it is imported
or shipped in an export. To use a file, move it back into the project through Godot's
FileSystem panel.
